# 枯山水 karesansui

**Markdownノートを、枯山水として眺める。**

任意のフォルダを指定すると、`.md` 1本が石になり、フォルダが岩島になり、砂紋がその周りに広がる。新しいノートほど墨が濃く、古いものは風化して薄くなる。配置はフォルダパスから決定論的に生成されるので、何度開いても「自分の庭」は同じ形。

## 特徴

- **依存ゼロ。** Python標準ライブラリのみ。npmもpipもビルドも不要
- **ローカル専用。** 127.0.0.1にのみバインド。ノートは1バイトも外に出ない
- **読み取り専用。** ノートフォルダには一切書き込まない
- **決定論的。** 庭のレイアウトはパスからseed生成。石は勝手に動かない

## 使い方

```bash
git clone https://github.com/kusonch9501-afk/karesansui.git
cd karesansui
python3 server.py            # 同梱のサンプル庭が開く
python3 server.py ~/notes    # 自分の庭が開く
```

Python 3.8以上のみ必要。

## 庭の読み方

岩島 = フォルダ(またはfrontmatterの`category`)、石 = md1本、石の大きさ = 文章量、墨の濃さ = 新しさ、苔 = タグ付き。ホバーでプレビュー、クリックで全文、`/`で検索(該当しない石は砂に沈む)。
